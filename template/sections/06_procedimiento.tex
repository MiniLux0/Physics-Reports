\section{Procedimiento Experimental}
\label{sec:procedimiento}

El procedimiento experimental se llevó a cabo siguiendo el orden cronológico detallado a continuación:

\begin{enumerate}
    \item \textbf{Calibración inicial:} Se verificaron las condiciones de cero y se registraron las dimensiones iniciales con el instrumento correspondiente.
    \item \textbf{Montaje del sistema:} Se instalaron los componentes asegurando la alineación y el contacto adecuado entre las partes móviles y los apoyos fijos.
    \item \textbf{Toma de datos:} Se realizaron las mediciones directas registrando los valores y sus incertidumbres instrumentales en la hoja de recolección de datos.
    \item \textbf{Repetición y verificación:} Se repitió el proceso para las distintas configuraciones o muestras de prueba.
\end{enumerate}
